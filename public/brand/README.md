# EloGest — Pacote De Identidade Visual Para Aplicação

## Arquivos Principais

- `elogest-logo-horizontal.svg`: logotipo horizontal vetorial para telas claras.
- `elogest-logo-horizontal-dark.svg`: versão vetorial para fundos escuros.
- `elogest-logo-header-640.png`: PNG transparente para topbar e sidebar.
- `elogest-logo-pdf-1200.png`: PNG transparente recomendado para o cabeçalho de PDFs oficiais.
- `elogest-icon.svg`: ícone vetorial principal.
- `elogest-icon-dark.svg`: ícone vetorial para fundo escuro.
- `elogest-icon-512.png`: ícone para PWA e materiais digitais.
- `elogest-icon-192.png`: ícone PWA.
- `elogest-icon-180.png`: Apple Touch Icon.
- `elogest-icon-64.png`: usos compactos.
- `favicon.ico`: favicon para navegador.
- `site.webmanifest`: manifesto básico para PWA.

## Paleta

- Verde Principal: `#256D3C`
- Verde Escuro: `#174828`
- Verde Claro: `#8ED08E`
- Grafite: `#17211B`
- Verde Muito Claro: `#EAF7EE`
- Branco: `#FFFFFF`

## Estrutura Recomendada No Projeto

Copie os arquivos para:

```text
public/brand/
```

Use no cabeçalho interno:

```text
/brand/elogest-logo-header-640.png
```

Use no gerador de PDFs:

```text
/brand/elogest-logo-pdf-1200.png
```

Use como ícone PWA:

```text
/brand/elogest-icon-192.png
/brand/elogest-icon-512.png
```

Use como favicon:

```text
/brand/favicon.ico
```
